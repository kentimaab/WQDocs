# Plug-ins

Kentima bygger plugins som utökar WideQuick-projekt byggda på Modular Framework. Varje plugin är utformad för att vara enkel plug-and-play. Importera den som en resurs så är den redo att användas, utan att behöva skriva några skript.

Den här sidan uppdateras löpande i takt med att fler plugins släpps.

## Tillgängliga plugins { #tillgangliga-plugins }

### [Teltonika SMS](teltonika/oversikt.md) { #teltonika-sms }

Skicka SMS-aviseringar direkt från WideQuick via en Teltonika-routers inbyggda REST API, som en direkt ersättning för det inbyggda GSM-modem-systemet.

* [**Översikt**](teltonika/oversikt.md) — vad pluginet gör och vilka routrar som stöds.
* [**Installation**](teltonika/installation.md) — importera pluginet som en resurs.
* [**Användning**](teltonika/anvandning.md) — konfigurera pluginet och skicka SMS.
* [**Avancerat**](teltonika/avancerat.md) — certifikat, funktionsreferens och felsökning.
