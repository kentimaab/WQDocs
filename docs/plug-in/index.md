# Plug-ins

Kentima builds plugins that extend WideQuick projects built on the Modular Framework. Each plugin is designed as an easy, plug-and-play addition. Import it as a resource and it's ready to use, without writing any scripts.

This page is updated continuously as more plugins are released.

## Available plugins { #available-plugins }

### [Teltonika SMS](teltonika/oversikt.md) { #teltonika-sms }

Send SMS notifications directly from WideQuick through a Teltonika router's built-in REST API, as a drop-in replacement for the built-in GSM Modem system.

* [**Overview**](teltonika/oversikt.md) — what the plugin does and which routers are supported.
* [**Installation**](teltonika/installation.md) — importing the plugin as a resource.
* [**Usage**](teltonika/anvandning.md) — configuring the plugin and sending SMS.
* [**Advanced**](teltonika/avancerat.md) — certificates, function reference, and troubleshooting.
